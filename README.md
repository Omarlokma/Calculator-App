# A Simple Calculator App

A lightweight calculator made with **HTML, CSS, and JavaScript**.  
It performs basic math operations and has a clean, modern interface.

---

## ✨ Features
- ➕ Addition, ➖ Subtraction, ✖️ Multiplication, ➗ Division
- Support for decimals and parentheses
- **C** → Clear all input  
- **DEL** → Remove last digit  
- **=** → Evaluate the expression
- Error handling for invalid input
- Minimal responsive design with hover effects
